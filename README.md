# Quantum
Quantum is an open-source neural network built from scratch in C++. It uses a non-transformer architecture based on wave token interaction and complex numbers.
Project Structure
Math-Core/: Core mathematical engine (complex numbers, matrices, wave vectors).
Material/: Directory for training data (.cpp, .hpp source files).
Logic-Intelligence/: Storage for trained weights and model states.
Logic-Intelligence/Logs/: System logs (train_logs.txt, error_logs.txt).
Quick Start
1.Clone the repository:git clone https://github.com/data-123-fog/Quantum.git
cd Quantum
2.Add training data: Place your source files (.cpp, .hpp) inside the Material/ directory.
3.Compile: Build the project using your C++ compiler (requires C++17 support).
